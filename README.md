# Telegram Online Status Bot

Telegram-бот для входа в аккаунт Telegram через userbot-клиент (Telethon) и отслеживания онлайн-статуса пользователей.

## Возможности

- Вход в Telegram-аккаунт через бота (ввод номера, кода, облачного пароля)
- Проверка статуса подключения
- Выход из аккаунта
- Отслеживание онлайн-статуса пользователя (проверка каждые 5 минут)
- Уведомления об изменении статуса (в сети / не в сети / был недавно и т.д.)

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/extazz1r/telegramm-online-status.git
cd telegramm-online-status
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Скопируйте `.env.example` в `.env` и заполните:
```bash
cp .env.example .env
```

### Получение API_ID и API_HASH

1. Перейдите на https://my.telegram.org/apps
2. Войдите в свой аккаунт
3. Создайте приложение и скопируйте `API_ID` и `API_HASH`

### Получение BOT_TOKEN

1. Напишите @BotFather в Telegram
2. Создайте нового бота командой `/newbot`
3. Скопируйте токен

### Получение ADMIN_ID

1. Напишите @userinfobot в Telegram
2. Он покажет ваш ID

## Запуск

```bash
python bot.py
```

## Команды бота

| Команда             | Описание                                      |
|---------------------|-----------------------------------------------|
| `/start`            | Приветствие и список команд                   |
| `/login`            | Начать вход в аккаунт                         |
| `/status`           | Проверить статус подключения                  |
| `/logout`           | Выйти из аккаунта                             |
| `/cancel`           | Отменить процесс входа                        |
| `/watch username`   | Начать отслеживание онлайн-статуса пользователя |
| `/unwatch`          | Прекратить отслеживание                       |

## Процесс входа

1. Отправьте `/login`
2. Введите номер телефона (например: `+79001234567`)
3. Введите код подтверждения через пробелы/дефисы (например: `1 2 3 4 5`)
4. Если включена 2FA — введите облачный пароль

## Отслеживание статуса

1. Войдите в аккаунт через `/login`
2. Отправьте `/watch username` (с `@` или без)
3. Бот проверяет статус каждые 5 минут и присылает уведомление при изменении
4. Для остановки отправьте `/unwatch`

Возможные статусы:
- **В сети** — пользователь онлайн
- **Не в сети** — с указанием времени последнего захода
- **Был(а) недавно** — скрытый статус, был недавно
- **Был(а) на этой неделе** / **в этом месяце**
- **Статус скрыт** — настройки приватности не позволяют видеть статус
